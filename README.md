# Sample RabbitMQ MassTransit

Example of how to use only RabbitMQ in two-way communication between .NET 8 microservices

> [!NOTE]
> In the [SampleWithMassTransit](https://github.com/AngeloDotNet/NET8-SampleRabbitMQMassTransit/tree/SampleWithMassTransit) branch, the version that uses MassTransit with RabbitMQ for two-way communication between .NET 8 microservices is available.
